# 「アカウントを削除」（a485 switch、App Reviewの要件）— 置き場と文の基準

[全体図](overview.md) / [ログインと購読の切替](login-billing.md)。Tronieの裁定（2026-11-23）：切替の版で全プラットフォームに同じ入口を置く。a540（Mint・Tronie 2026-11-23）：どのサーバーにもアカウントが無くなったので、BellTeam側の削除は`signOutLocal`（アプリが持つものをすべて消す）になる。下の文は**Apple版の案**で、Poliの最終確認とほかのOSの写しはTronieが回す。これは Mac（iPhone・iPad も同じコード）の基準で、Windows（Anis）・Linux・Android（Neon）はこの置き場と文をそのまま写す。

## 置き場

設定 > 利用と課金 > 「BellTeamの購読」カード（`StoreAccountCard`）の**最後**。区切り線の下に、囲み線つきの破壊的なボタン 1 つ「アカウントを削除」。サインインしていなくても出す（この端末に残ったサインイン・鍵・データを消せるように）。

## 文（日本語が契約。2026-11-23 Mintの読みのR1・R2で改めた）

| どこ | 文 |
| --- | --- |
| ボタン | 「アカウントを削除」 |
| 確認の題 | 「アカウントを削除しますか？」 |
| 確認の本文 | 「この端末のBellTeamのサインインと、受け取った購読の確認を消します。決裁箱のサインインと鍵、サーバーのトークン、保存した会話の写しも消して、最初の画面に戻ります。BellTeamは、名前・メールアドレス・購入の記録を、サーバーにも運営にも持っていません。決裁箱は、サインインを終えるだけです。決裁箱のアカウントと申請は消えません。消すには、決裁箱のアプリでアカウントを削除してください。決裁箱の運営には、止めたサインインのランダムな番号も最長14日残ります。ほかの端末のサインインは、その端末で終えてください。購読はAppleのものなので、この操作では解約されません。解約は「設定」のApple Accountの購読から行ってください。サーバーの会話や設定は消えません。」 |
| 確認のボタン | 「削除する」（破壊的）／「やめる」 |
| 結果の題（両方のサインアウトが通った時だけ） | 「アカウントを削除しました」 |
| 結果の本文 | 「この端末のサインインとデータを消しました。BellTeamの運営は、あなたに関する情報を持っていません。あなたのサーバーの会話と設定は残ります。決裁箱のアカウントは、決裁箱のアプリで削除するまで残ります。購読を止めるには、Apple Accountの購読の管理から解約してください。」 |
| 終えられなかった時の題 | 「アカウントの削除を終えられませんでした」 |
| 終えられなかった時の本文 | 「<部分>を消せませんでした（<理由>）。つながる場所でもう一度「アカウントを削除」を押すと、続きから終えます。すでに終えた手順はそのままです。」 部分は「決裁箱のサインイン」「BellTeamの購読の確認」（両方なら「と」でつなぐ）。理由は「ネットワークにつながっていません」「決裁箱の運営に届きません」「処理できませんでした」の3つ。 |

「購読はAppleのもの」の文だけ、他のプラットフォームは自分のストアの言葉（購入した先の購読の管理）に置き換える。それ以外の語は変えない。

## 何をするか（順序。R1：消えていないものを「消えた」と言わない）

1. **先に2つのサインアウト**を終える：決裁箱（2つ目の接続、`ApprovalBoxLink.removePass`）とBellTeam（`LocalAccount.removeLocal`＝`signOutLocal`：この端末のサインインと受け取った返事。通信は要らない）。ライブラリは運営に届かなかった時（通信の失敗・5xx）は**何も消さずに投げる**ので、ここは握りつぶさず、そのまま失敗として扱う。両方を試し、通ったものは通ったまま残す。消すものが何も無い時は何もしない（押し直しが終えた手順を繰り返さない）。
2. **どちらかが失敗したら止める**：設定の画面に残り、失敗の本文（部分と理由）だけを出す。端末の鍵・保存したデータ・サーバー接続には触れない。つながる場所で同じボタンを押すと、残りだけをやり直す。
3. **両方が通った時だけ**：決裁箱の端末の鍵・レジストリの写し・履歴を消し（`ApprovalBoxLink.deleteLocalData`）、接続を外す（`AppStore.changeServer`＝ホームのセッションを終え、通知の登録を外し、共有Keychainの接続先とトークンを消し、会話・下書き・写しを捨てて最初の画面へ）。
4. 最初の画面の上に、結果の題と本文を1回だけ出す。

「ほかの端末を止める」は含めない（それは「端末をなくした時」の別の入口で、Appleのシートが要る）。この操作で止めるのは、この端末のサインインだけ。BellTeamに残る記録は無い（a540。「ほかの端末をすべて止める」の記録もBellTeamには無い）。運営側に残るのは、決裁箱の止めたサインインのランダムな番号（最長14日）だけで、決裁箱のアカウントと申請は決裁箱のアプリで削除するまで残る。

試験：`AccountDeletionTests`（文言の固定、失敗の本文と「両方を試す」、削除後の最初の画面）。
