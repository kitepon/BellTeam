# ADR 0001: Bot間の直接メッセージは宛先tmuxへ即時配達する

## 状態

採用

## 決定

BellTeam の Bot 間直接メッセージは、MCP ツール `sendmessage(target, message)` から宛先 Bot の tmux セッションへ即時配達する。受信箱と受信用ポーラーは持たない。

ツールは送信元 Bot を環境から特定し、宛先 Bot の定義、セッションの生存、CLI の前面状態を確認する。セッションが無ければ定義済みの CLI を起動する。CLI ごとの TUI 操作差はツール内のアダプタで処理し、Bot や呼び出し側へ選択させない。

## 理由

全 Bot が同じコンテナの tmux で常駐する。宛先セッションが直接の配達先になり、受信箱の監視周期や未読管理を追加せずに会話を開始できる。

## 受入

`bell-grok-a` と `bell-grok-b` の実 CLI が同じツールを使い、直接メッセージを一往復する。停止中の宛先はツールが再起動してから受理させる。
