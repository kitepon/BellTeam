# 「アカウントを削除」（a485 switch、App Reviewの要件）— 置き場と文の基準

[全体図](overview.md) / [ログインと購読の切替](login-billing.md)。Tronieの裁定（2026-11-23）：切替の版で全プラットフォームに同じ入口を置く。これは Mac（iPhone・iPad も同じコード）の基準で、Windows（Anis）・Linux・Android（Neon）はこの置き場と文をそのまま写す。

## 置き場

設定 > 利用と課金 > 「BellTeamのアカウント」カード（`StoreAccountCard`）の**最後**。区切り線の下に、囲み線つきの破壊的なボタン 1 つ「アカウントを削除」。カードは運営のWorkerの接続先が設定されている時だけ出る（`StoreAccount.configured`）。サインインしていなくても出す（この端末に残ったパス・鍵・データを消せるように）。

## 文（日本語が契約。2026-11-23 Mintの読みのR1・R2で改めた）

| どこ | 文 |
| --- | --- |
| ボタン | 「アカウントを削除」 |
| 確認の題 | 「アカウントを削除しますか？」 |
| 確認の本文 | 「この端末のBellTeamのサインインを、届く限りすべて終わらせます。この端末にある店のパス・アカウントの番号・サーバーのトークン・決裁箱のサインインと鍵・保存した会話の写しを消して、最初の画面に戻ります。ログインの運営は、名前・メールアドレス・購入の記録を持っていません。運営に残るのは、止めたパスのランダムな番号と、「ほかの端末をすべて止める」を使った時のアカウントの番号とその時刻だけで、どちらも最長14日で消えます。ほかの端末のサインインは、その端末で終えてください。購読はAppleのものなので、この操作では解約されません。解約は「設定」のApple Accountの購読から行ってください。サーバーの会話や設定は消えません。」 |

「購読はAppleのもの」の文だけ、他のプラットフォームは自分のストアの言葉（購入した先の購読の管理）に置き換える。それ以外の語は変えない。

## 何をするか（順序。R1：消えていないものを「消えた」と言わない）

1. **先にライブラリの2つのサインアウト**を終える：決裁箱（2つ目の接続、`ApprovalBoxLink.removePass`）とBellTeam（`StoreAccount.removePass`、店のパス・K・購入の印・承認した端末の一覧）。ライブラリは運営に届かなかった時（通信の失敗・5xx）は**何も消さずに投げる**ので、ここは握りつぶさず、そのまま失敗として扱う。両方を試し、通ったものは通ったまま残す。消すものが何も無い時は何もしない（押し直しが終えた手順を繰り返さない）。
2. **どちらかが失敗したら止める**：設定の画面に残り、失敗の本文（部分と理由）だけを出す。端末の鍵・保存したデータ・サーバー接続には触れない。つながる場所で同じボタンを押すと、残りだけをやり直す。
3. **両方が通った時だけ**：決裁箱の端末の鍵・レジストリの写し・履歴を消し（`ApprovalBoxLink.deleteLocalData`）、接続を外す（`AppStore.changeServer`＝ホームのセッションを終え、通知の登録を外し、共有Keychainの接続先とトークンを消し、会話・下書き・写しを捨てて最初の画面へ）。
4. 最初の画面の上に、結果の題と本文を1回だけ出す。

「ほかの端末を止める」は含めない（それは「端末をなくした時」の別の入口で、Appleのシートが要る）。この操作で止めるのは、この端末のサインインだけ。運営に残るものの正本は、ログイン部品の privacy-facts.md（止めたパスの番号は最長14日、「ほかの端末をすべて止める」を使った時のアカウントの番号と時刻は最長14日）。

試験：`AccountDeletionTests`（文言の固定、失敗の本文と「両方を試す」、削除後の最初の画面）。
