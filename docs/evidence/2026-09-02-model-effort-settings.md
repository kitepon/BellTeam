# 作成済みBotのモデル・エフォート変更

確認日: 2026-09-02

## 仕様

- Bot作成後も設定画面からモデルIDとエフォートを変更できる。
- モデルまたはエフォートが空欄なら、選択中CLIの既定値を使う。
- 同じCLIで明示値を変更する場合は、現在の処理と待機配送が終わってからAitermの実行中セッションへ反映し、会話文脈を保持する。
- CLIの既定値へ戻す場合とCLI自体を変更する場合は、Throughline引き継ぎ付きでセッションを再起動する。
- 停止中のBotは設定だけを保存し、次のメッセージから新設定を使う。
- エフォートは`low`、`medium`、`high`、`xhigh`、`max`、`ultra`を選べる。`ultra`はCodexだけが受け付ける。
- Cursorでエフォートを指定する場合はモデルIDも必須とする。
- Aitermが受け付けないモデルや組み合わせは保存せず、別設定へのフォールバックも行わない。
