# RTKとの接点

担当：ドリリー。RTK製品とhook公開仕様。

図・接続契約の正本は[RTKの機能図](/srv/bellteam/bots/bot-7fdb0410/docs/rtk-architecture.md)。RTK公式のTECHNICAL.mdとsrc/hooks/README.md、testgate担当の正本へそこから辿る。製品内部を複製しない。

`hook`はClaude/Codex/Cursorのstdin JSON→stdout JSON・stderr・終了値、Grokはrewrite中継。testgateの選択/中継はシラツル、RTK製品と端末導入はドリリー、本体のcli-registration/共有設定はエピネル、配布はセンチ、統合はトロニー。RTK不在やtimeoutの契約は正本へ従い、許可や配送成功を付け足さない。
