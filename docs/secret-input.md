# 秘密情報の入力

Botがトークンやパスワードを必要とするとき、BellTeamの共通MCP `request_secret` で入力を依頼する。iPhoneとWebの会話に依頼文とカードが表示され、利用者が専用欄から登録または取消を行う。

## Botの使い方

```json
{
  "toolId": "github",
  "label": "GitHubトークン",
  "message": "GitHubに接続するためのトークンを入力してください。"
}
```

ルームでの依頼は所属している `roomId` を追加する。省略時は依頼したBotとの個別会話に表示する。入力を待ってツールを呼び続けず、現在のターンを終了する。

登録・取消は依頼Botへの既存のユーザーメッセージ配送で通知する。登録通知にはファイルの保存先が入り、秘密の値は入らない。`get_secret_request({"requestId":"依頼のID"})` でも状態と保存先を確認できる。

保存ファイルは利用するプログラムから読み、標準入力またはサービスの認証APIへ渡す。`cat`、`print`、シェルのトレースなどで値をツール出力・会話・ログへ表示しない。秘密の値をMCP引数へ転記しない。GitHub CLIの場合は `gh auth login --with-token < 保存ファイル` のように標準入力を利用する。

## 保存と通信

- 機能はコンテナに標準搭載する。秘密の実値は利用者の永続領域 `$BELLTEAM_ROOT/shared/tools/<toolId>/secrets/<requestId>` に保存し、イメージやGitには含めない。
- 保存ファイルは `0600`、秘密用ディレクトリは `0700`。ディスク上の値は平文であり、既存のバックアップに含まれ得る。コンテナ内の同一ユーザーとして動くBotとホスト管理者は読める。Botごとの秘密分離や暗号化保管庫ではない。
- 値はCloudflare Accessで認証したHTTPSの専用POSTで受け取る。会話API、MCP結果、SSE、リクエストのメタデータ、診断ログには入れない。
- Webはリダイレクトを拒否するfetch、iPhoneはキャッシュを保存しないURLSessionとリダイレクト拒否を用いる。認証画面への転送先にPOST本文を送らない。
- 入力欄はマスク表示し、送信時・閉じた時・アプリが非アクティブになった時に消去する。値を端末の設定やストレージへ保存しない。
- 登録済みの依頼は再登録できない。変更が必要なら新しい依頼を作る。取消では秘密ファイルを作らない。不要になった秘密ファイルは、利用したBotまたはホスト管理者が削除する。

依頼のメタデータは `$BELLTEAM_ROOT/state/secret-requests/` に置く。会話APIへ合流し、既存のSSEで更新を知らせる。秘密ファイルを会話ストア・RAGの入力には使わない。

## 失敗時

登録処理の例外本文・スタックには入力値が混ざり得るため、この入口では固定のエラーコードだけを診断へ送る。画面にも例外本文を表示しない。

値の保存とAIへの通知は別処理である。通知に失敗した場合は「登録済み」と「AIへの通知に失敗」を同時に表示する。自動再送は行わず、利用者が通常チャットで登録完了を知らせられる。プロセスが保存途中で止まった場合も自動で上書きせずエラーとし、管理者が状態を確認する。

## プロトコルの位置づけ

MCPのform elicitationで秘密を返す実装ではない。MCPでは依頼と状態だけを扱い、値はBellTeamのUIから専用HTTPS経路へ渡す。根拠となる外部仕様は [RAGの目録](../rag/INDEX.md) を参照。

## 検証

`node --test test/secret-requests.test.mjs` で保存の永続性、二重送信、取消、ルーム、MCPの呼出元、HTTP認証、HTTPS、SSE、診断への値の混入を確認する。

iPhoneの `SecretInputUITests` は `scripts/secret-input-smoke.mjs` が起動するローカルHTTPSサーバーにダミーの値を送る。新規の専用シミュレーターへ試験用証明書を追加し、`TEST_RUNNER_BELLTEAM_SECRET_SMOKE=1` を付けて実行する。終了後はそのシミュレーターを削除する。本番のユーザー設定や秘密の値は試験に使わない。
