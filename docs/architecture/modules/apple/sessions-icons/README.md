Icons of the sessions screen (a529a). One monochrome glyph per app kind, drawn in the muted text colour inside a 32 pt rounded tile (corner radius 8, tile fill = the card's secondary fill); the accessibility label is the kind's name. apple, linux, android: simple-icons (CC0 1.0); windows and web: drawn for this project. Every platform uses these same files (convert to PDF/vector assets or draw the paths natively); do not substitute another set.
