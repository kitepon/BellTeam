# ADR 0002: ユーザー会話とBot間活動を分離して表示する

## 状態

採用

## 決定

BellTeam Web UIの個別チャットは、ユーザーと選択Botの1対1会話を主表示とする。

Botが別のBotへ送ったメッセージ、または別のBotから受け取ったメッセージは、通常の会話吹き出しにしない。タイムラインへ送受信を示す1行の折りたたみ行を置き、ユーザーがタップした時だけ本文と相手を表示する。

ユーザーは予約ID `user` として扱う。UIからBotへの入力は既存のtmux transportで直接配達し、Botからユーザーへの返答は既存MCPの `sendmessage(target="user", message)` でJSONLへ記録する。Bot間通信のMCP仕様 `sendmessage(target, message)` は変えない。

公開認証の決定は[ADR 0003](0003-cloudflare-access.md)へ更新した。

更新通知はSSEで行う。Bot間配達は従来どおりtmuxへの直接投入であり、受信箱やBot側ポーリングは追加しない。

## 理由

ユーザー会話へBot同士の全文を混ぜると、誰と話しているかが崩れる。一方でBotが裏で相談した事実を隠すと、判断過程が見えない。折りたたみ行なら、主会話を保ったまま必要な時だけ詳細を確認できる。

## 受入判断

スマホUI上でユーザー発言とBot返答が通常の吹き出しになり、Bot間の往復が送受信各1行として折りたたまれていれば採用する。公開URLから無認証でAPIを呼べる場合は不採用とする。
