# 作成済みBotのCLI変更

確認日: 2026-09-02

## 仕様

- 作成済みBotも設定画面のCLI欄からGrok、Codex、Claude、Cursorを選べる。
- CLIを変更してもBot IDとプロジェクトは変えない。個人長期記憶、RAG、予定、会話ログ、その他のBot固有ファイルは同じ永続領域に残る。
- 稼働中なら現在の処理と待機配送を終えてから旧セッションを閉じ、選択したCLIを起動する。
- 停止中なら設定だけを保存し、次のメッセージで選択したCLIを起動する。
- 新しいCLIの初回起動には、同じプロジェクトの最新Throughline sessionと長期記憶補足を渡す。
