# AI認証画面の配布と実認証の確認

目的は、AIの認証が切れてメンバーが止まった時に、オーナーがAppleアプリから公式認証へ入り直せること。実装と試験は完了し、配布と本人の操作を含む確認を進める。状態・配布物・検証結果は[準備状況の正本](subscription-setup.json)の`integration.appHarnessAuthentication`、実装と試験の説明は[検証記録](evidence/2026-10-06-app-harness-auth.md)を参照する。

## 残る作業

1. mainへpushした実装からiOS・Macの配布用archiveを書き出し、既存のオーナー用TestFlightグループへ配布する。
2. 導入したMac・iPhoneで、設定のAI一覧と公式の現在の状態を確認する。閲覧の段階では認証を開始しない。
3. オーナーの許可後、開始前にトロニーへ連絡する。トロニーが実行中のCodex席が無いことを確認し、サーバーの観測を用意してから始める。
4. アプリから公式の認証を開始し、オーナーが公式サイトで承認する。入力が必要な場合は同じ画面から渡し、認証済みへの遷移とメンバーの応答を確認する。

Codexは開始時に今の認証を消すため、3と4は許可前に実行しない。試験専用の常設サーバーは無く、今回の画面試験は本番と切り離したHTTP fixtureで行った。公式認証を最後まで通したとはまだ扱わない。ASCへの再提出と本番コンテナの再起動はこの作業に含めない。
