# Windows版をMac版と同水準へ仕上げる

## 完了条件

Mac版の実画面と操作を品質基準とし、Windows版の見た目・情報設計・操作性・機能を同水準以上へ仕上げる。Windowsの画面幅と操作に合う改善は担当者の判断で行い、共通に使える改善は理由と比較画像を添えてMac担当へ共有する。PRの作成だけで完了とせず、mainへの取り込み、FOXへの正規導入、実画面と通信の確認まで行う。

## 進める内容

- 一覧・会話・詳細の3ペイン、主画面内の予定・設定、追加メニュー、検索、情報の見出し、文字・色・余白・部品をMac版と照合して改修する。
- メンバー追加、編集・予定・設定の操作、会話・画像・カード・書き出し、画面表示とショートカットを比較し、不足を埋める。
- Accessログイン・初回設定、AI認証、起動中の通知も完成条件へ含める。途中のAccess・初回設定は専用ブランチの退避として保持し、画面改修後に統合する。
- Mac版の実画面をトロニー経由で取得し、Windows版の非表示描画と比較する。FOXでの前面表示は時刻を調整して実画面を確認する。

## 現在地

- FOXにはMac版の実画面を基準に再構成した画面改修版が導入済み。
- Mac版の実画面5枚を`docs/mac-ui-reference-48.md`から取得し、ソースの`DesktopWorkspaceView`、`BellTheme`、会話・編集・予定・設定と照合した。[画面改修の比較資料](windows-ui-progress.md)に、同じ人工データによるWindowsの4画面を置く。
- Access・初回設定・AI認証、通知、ログアウト・拒否理由・前面確認で見つけた表示と終了処理の修正はmainへ取り込まれ、FOXへ導入された。本番の本人ログインと認証開始は未確認。
- [画像閲覧の操作](windows-gallery-ui.md)もmainへ取り込まれ、FOXへ導入された。本人操作の結果はトロニーを通して受け取る。
- 非表示の画面内移動・新着・履歴追加・画像切替と単体試験は成功。FOXの前面確認では一覧・会話・予定・設定と下書き保持、二重起動後の1窓維持と通常終了を確認した。通常の利用者から位置保存と通知オフの保存も突合できた。未確認の項目は[前面確認の記録](windows-final-check.md)へ集約する。

## 守る範囲

Windows・試験・文書を変更し、iOS・Web・サーバーのコードは読む。本番へAI認証を始める操作と設定変更の試験は送らず、模擬で確かめる。導入と取り込みはトロニーが行う。本人のログインと前面の操作確認は、必要な成果を用意してから調整する。

[前面確認と残る項目](windows-final-check.md)を完了判定の確認一覧とする。通知の非表示要求は通常の利用者でも成功した。実際のポップアップとクリック、IME、画像の操作、書き出し保存、倍率変更などは未確認。必要な本人操作の結果を受け取り、不具合があれば再現と修正を行うまでゴールを完了にしない。
