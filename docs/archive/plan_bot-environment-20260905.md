# Botの環境構築を可能にする

オーナー依頼: 各Botが自由に環境を構築できない問題を解消する。チャイム個人の業務移行は対象外。

所有者と保存先: BellTeam基盤の実装は開発リポジトリ `/Users/kite/Developer/BellTeam`、正規deployで本番 `/home/kite/BellTeam` へ反映する。Botが書く構築手順と環境設定は各自の `/srv/bellteam/bots/<bot-id>/environment/`。既存のBot台帳、業務コード、個別MCP登録は変更しない。

成功条件: コンテナ内でsudo、pipとvenv、基本ビルド道具を使える。Botの構築スクリプトを更新後にAIなしで再実行できる。Bot別の環境をCLI起動とコマンド予定へ渡し、他Botへ混ぜない。
