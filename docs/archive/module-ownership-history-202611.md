## 2026-11-03 共通実装（integration）の正式移管

Owner の正式割当により、`integration` モジュールの実装 owner および通常 main 統合（作者成果照合・必要結合・図合成・競合解消・push・CI/source binding・採用 SHA 返却）をモリーへ移管。Root（トロニー）は全体設計・公開契約・診断方針裁定・優先順位・本番・Owner 判断へ専念。

## 2026-11-08 本体担当の一本化

Owner 承認・トロニー伝達（2026-11-08）により体制を一本化：
- **モリー**：本体コンテナ（親の組立・`integration`・`runtime`・部品入れ替え・`distribution` のコードと image 定義）と「本体を止めずに更新できる」性質の唯一の担当。
- **エピネル**：通常 `main` の採用 gate 担当（`runtime` の所有はモリーへ移管）。
- **センチ**：製品試験・事前受入専任（商用配布のコード所有はモリーへ移管）。
- 部品の業務内部の各担当、および全体判断・本番実行のトロニーは変更なし。
