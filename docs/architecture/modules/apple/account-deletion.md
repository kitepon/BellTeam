# 「アカウントを削除」（a485 switch、App Reviewの要件）— 置き場と文の基準

[全体図](overview.md) / [ログインと購読の切替](login-billing.md)。Tronieの裁定（2026-11-23）：切替の版で全プラットフォームに同じ入口を置く。これは Mac（iPhone・iPad も同じコード）の基準で、Windows（Anis）・Linux・Android（Neon）はこの置き場と文をそのまま写す。

## 置き場

設定 > 利用と課金 > 「BellTeamのアカウント」カード（`StoreAccountCard`）の**最後**。区切り線の下に、囲み線つきの破壊的なボタン 1 つ「アカウントを削除」。カードは運営のWorkerの接続先が設定されている時だけ出る（`StoreAccount.configured`）。サインインしていなくても出す（この端末に残ったパス・鍵・データを消せるように）。

## 文（日本語が契約）

| どこ | 文 |
| --- | --- |
| ボタン | 「アカウントを削除」 |
| 確認の題 | 「アカウントを削除しますか？」 |
| 確認の本文 | 「この端末のBellTeamのサインインを、届く限りすべて終わらせます。この端末にある店のパス・アカウントの番号・サーバーのトークン・決裁箱のサインインと鍵・保存した会話の写しを消して、最初の画面に戻ります。ログインの運営は、このアカウントに結びつけた情報を持っていません。ほかの端末のサインインは、その端末で終えてください。購読はAppleのものなので、この操作では解約されません。解約は「設定」のApple Accountの購読から行ってください。サーバーの会話や設定は消えません。」 |
| 確認のボタン | 「削除する」（破壊的）／「やめる」 |
| 結果の題 | 「アカウントを削除しました」 |
| 結果の本文 | 「この端末のサインインとデータを消しました。ログインの運営には、このアカウントの情報は残っていません。購読を止めるには、Apple Accountの購読の管理から解約してください。」 |

Google Play・Stripeの購読の文はプラットフォームごと（Apple版はAppleの購読の管理）。他のプラットフォームは「購読はAppleのもの」の1文を、自分のストアの言葉（Google Playの購読の管理など）に置き換える。それ以外の語は変えない。

## 何をするか（順序）

1. 決裁箱：この端末のApproval Boxのサインインを外し、端末の鍵・レジストリの写し・履歴・添付を消す（`ApprovalBoxLink.deleteLocalData`）。Approval Box自身のアカウントは消さない。
2. 接続：`AppStore.changeServer`＝サーバーのセッションを終え（ホームのセッションは`endHomeSession`、ライブラリのsignOutはホームを終えない）、通知の登録を外し、共有Keychainの接続先とトークンを消し、会話・下書き・写しを捨てて、最初の画面へ戻る。
3. 店の側：ライブラリの`signOut`で店のパス・K・購入の印・承認した端末の一覧をこの端末から消す（`StoreAccount.deleteLocalAccount`）。運営へ届かなくても端末の記録は消す。ライブラリに「アカウント削除」の呼び出しは無い（運営はアカウントに結びつけた情報を持たない）。
4. 結果：最初の画面の上に、結果の題と本文の通知を1回だけ出す。

「ほかの端末を止める」は含めない（それは「端末をなくした時」の別の入口で、Appleのシートが要る）。この操作で止めるのは、この端末のサインインだけ。

試験：`AccountDeletionTests`（文言の固定、ボタンの置き場、削除の順序）。
